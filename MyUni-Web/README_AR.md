# MyUni Web — دليل التشغيل بالعربي

هذا مشروع ويب تجريبي تفاعلي لفكرة MyUni، مبني باستخدام React وVite. يحتوي على واجهات للطالب الجديد، وطالب التحويل، والطالب الحالي، والبرامج، ومساعد اختيار التخصص، ورحلة الطالب، والحياة الجامعية، والخدمات، ومساعد إرشادي تجريبي، ولوحة إدارة تجريبية.

## قبل ما تبدأ

1. نزّل وثبّت **Node.js LTS** من: https://nodejs.org/en/download
2. نزّل وثبّت **Visual Studio Code** من: https://code.visualstudio.com/download
3. فك ضغط ملف المشروع في مجلد واضح مثل `C:\Projects\MyUni-Web`.

## تشغيل المشروع على Windows 11

1. افتح VS Code.
2. من القائمة اختار **File > Open Folder** وافتح مجلد `MyUni-Web`.
3. من القائمة اختار **Terminal > New Terminal**.
4. اتأكد إن التيرمنال واقف داخل مجلد `MyUni-Web` (نفس المجلد اللي فيه package.json).
5. نفّذ الأمر التالي وانتظر لحد ما ينتهي:

   ```bash
   npm install
   ```

6. شغّل الموقع:

   ```bash
   npm run dev
   ```

7. افتح الرابط اللي يظهر في التيرمنال، غالبًا:

   `http://localhost:5173`

8. لإيقاف التشغيل ارجع للتيرمنال واضغط `Ctrl + C`.

## اختبار البناء النهائي

لتتأكد إن المشروع قابل للبناء:

```bash
npm run build
```

لو انتهى الأمر من غير أخطاء، ستجد نسخة النشر في مجلد `dist`.

## إيه اللي شغال في النسخة الحالية؟

- تنقل بين صفحات الويب الأساسية.
- تبديل دور العرض بين طالب جديد / طالب تحويل / طالب حالي.
- تبديل الواجهة بين العربية والإنجليزية في العناصر الأساسية.
- البحث عن البرامج وتصفيتها وحفظ البرامج المفضلة.
- مساعد اختيار التخصص بناءً على الاهتمامات المختارة.
- متابعة قائمة الرحلة وتسجيل الخطوات المكتملة.
- حفظ الاهتمام بفعاليات تجريبية.
- إرسال طلبات خدمة تجريبية.
- مساعد إرشادي محلي بإجابات محددة للكلمات الأساسية.
- لوحة إدارة محلية لإضافة فعاليات تجريبية.
- حفظ معظم بيانات العرض في `localStorage` داخل المتصفح.

## مهم جدًا قبل استخدامه كموقع حقيقي

هذه النسخة **واجهة MVP تجريبية** وليست نظام جامعة إنتاجيًا.

- البيانات المعروضة أمثلة؛ لازم تستبدلها بمعلومات معتمدة من الجامعة.
- مساعد MyUni الحالي ليس نموذج ذكاء اصطناعي متصلًا بالإنترنت أو بقاعدة بيانات الجامعة؛ إنه مساعد تجريبي بإجابات محلية محددة.
- تسجيل الدخول الحقيقي، وقاعدة البيانات المشتركة، وصلاحيات الإدارة، والإشعارات الفعلية تحتاج Backend مثل Supabase أو Firebase وإعدادًا آمنًا.
- طلبات الخدمات والفعاليات تحفظ داخل المتصفح المستخدم فقط، ولا تصل إلى موظفي الجامعة.
- لوحة الإدارة الحالية للعرض فقط وغير محمية؛ لا ترفعها لإدارة بيانات حقيقية قبل إضافة المصادقة والتحقق من الصلاحيات من جهة الخادم.
- روابط LMS والبوابة الجامعية لم تُضف لأن الروابط الرسمية غير متوفرة في المشروع التجريبي.

## لو ظهر خطأ

- تأكد أنك فتحت المجلد الذي يحتوي على `package.json`.
- تأكد من تثبيت Node.js، ثم أغلق التيرمنال وافتح Terminal جديدًا.
- نفّذ `node -v` و `npm -v` للتأكد من وجود Node وnpm.
- لو غيّرت ملفات المشروع والسيرفر شغال، غالبًا الصفحة هتتحدث تلقائيًا.
- لو ظهر خطأ في `npm install`، تأكد من اتصال الإنترنت ثم أعد المحاولة.
